# FreshMart | Online Grocery Shopping Platform

FreshMart is a full-stack e-commerce web application designed to make online
grocery shopping convenient and accessible. Users can explore grocery products,
manage their shopping carts, and place orders through a user-friendly interface.

The project demonstrates my skills as a Full-Stack Web Developer, using the
MERN stack and related web technologies to build a practical e-commerce solution.

## Live Demo

Visit FreshMart: https://freshmart-4dvn.onrender.com/

## Project Overview

FreshMart provides an online platform where customers can browse grocery
products and shop through a responsive web interface.

The application is built with a React frontend and a Node.js and Express.js
backend, with MongoDB used for data storage.

The project focuses on full-stack development, REST API integration,
database management, authentication, and e-commerce functionality.

## Features

### Customer Features

- Browse available grocery products.
- View individual product details.
- Navigate products using their URLs.
- Add products to the shopping cart.
- Adjust product quantities.
- Manage cart items.
- Register and log in to an account.
- Access protected features where authentication is required.
- Place orders through the checkout process.

### E-commerce Features

- Product catalogue and product details.
- Shopping cart management.
- Backend API integration.
- Database-backed product management.
- Order processing.
- Payment integration where configured.

### Development Features

- RESTful API architecture.
- React component-based frontend.
- Express.js backend.
- MongoDB database integration.
- Environment-based configuration.
- Client-server communication using Axios.
- Responsive user interface.
